# PRIME Icon Mark

The **icon mark** is the standalone double-chevron (no wordmark). Use it as a favicon,
app icon, watermark, bug, or accent where the full logo is too large. These are the
official PRIME marks, embedded here as transparent PNGs.

## Files (bundled)

| File | Variant | Use on |
|---|---|---|
| `blue_icon_1.png` | Blue | Light / Warm White |
| `blue_gold_icon_1.png` | Blue + Gold duotone | Light / formal-premium |
| `silver_gold_icon_1.png` | Silver + Gold duotone | Neutral / sophisticated premium |
| `white_icon_1.png` | White | PRIME Blue `#003366` |
| `white_gold_icon.png` | White + Gold duotone | PRIME Blue, premium moments |

## Selection guide
- **Warm White `#FFFCFB`:** primary `blue_icon_1.png`; premium `blue_gold_icon_1.png`.
- **PRIME Blue `#003366`:** primary `white_icon_1.png`; premium `white_gold_icon.png`.
- **Sophisticated on either surface:** `silver_gold_icon_1.png`.

Gray and Deep Ink backgrounds are retired, so the white marks now live on Blue.

## Notes
- Transparent backgrounds, ~2400px on the long edge. Do not substitute a redrawn,
  traced, or AI-generated mark — only these official files are acceptable.
